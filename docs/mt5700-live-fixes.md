# MT5700 首轮试用修复

2026-09-12，GL-MT3600BE / ImmortalWrt 25.12-SNAPSHOT。
命令依据：用户提供的《MT5700M-CN 5G 系列模组 AT 命令手册》，01 版，2024-05-17。
手册和实机原始响应保存在本地，不提交原文、身份标识或凭据。

## 设备发现

非 AT 端口的正常探测失败单独放入 probe_notes。至少一个端口识别成功时，
页面显示识别结果，其他候选端口记录折叠展示；全部失败时仍返回清晰错误。
实机确认 ttyUSB1 成功，另外三个串口无识别响应，不代表整个模组识别失败。
修复 Vue 响应式对象不能直接 structuredClone 导致的“添加到配置”异常。

## 联网

未指定数据网卡时，只允许自动选择同一物理模组下唯一的网卡；不猜测其他路由器端口。
查询现有 OpenWrt 接口，识别同一网卡已经联网的情况，返回现有状态，不建立重复 DHCP。
已有其他 OpenWrt 接口管理时，断开和重拨由 LuCI 管理，后台显示入口及明确原因。
网络设置保存前重新读取其他配置字段，避免覆盖别的页面新保存的短信和启动设置。

手册第 16.1 节（383–384 页）规定 NDISDUP 参数为 cid,connect。
修正 PDP 非 1 时的参数颠倒和断开时 cid=0：建立使用 cid,1，断开使用 cid,0。
实机的 eth2 已由 LuCI mt5700 接口取得地址；本次确认点击连接返回 connected，
未执行中断现有连接的拨号或断开测试。

## 状态

增加 COPS?、^ICCID?（第 11.3 节，239–240 页）、^HFREQINFO?（第 13.16 节，314–316 页）。
解析 LTE/NR 的 PCC/SCC、频段、中心频点、上下行频率和带宽；LTE 频率按 100 kHz 换算。
MONSC 的驻留频点与 HFREQINFO 的载波中心频点分别显示，不相互覆盖。
号码等可选查询失败不再把整个状态标为失败，失败明细继续保留在查询响应中。
进入模组页面自动读取状态，切换模组清除旧设置值，增加网络偏好读取按钮。

实机确认运营商正常、ICCID 非空、NR n1、上下行带宽 40000 kHz；CNUM 返回错误，
号码显示未提供。NR 不提供传统 RSSI 的场景仍显示未提供，以服务小区的 RSRP/RSRQ/SINR 为准。

## 浏览器

局域网 HTTP 不提供 crypto.randomUUID，曾导致短信页初始化失败。
改用 crypto.getRandomValues 生成 UUID v4，保持发送幂等键规则。
配置加载失败时，联网、维护和转发页面现在显示错误，不再只留下空白页。
短信端口留空规范化为 null，避免配置校验将空字符串当成设备路径。
