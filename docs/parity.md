## 厂商

上游现存适配：quectel、fibocom、huawei、simcom、neoway、telit、foxconn、gosuncn、openluat、thales、meig、sierra。另有 generic 通用逻辑。每个厂商内部的平台差异也需要保留，不能只按厂商名称选择一个命令。

## 基线接口

`rpc-methods.json` 保存上游 qmodem RPC 的方法和入参。HTTP 路径可以重新设计，但迁移清单必须覆盖原方法的业务含义，以及页面直接调用的 UCI、文件和服务操作。短信的 qmodem.sms 接口另外追踪。

## 验证分层

1. 主机测试：TOML、响应解析、端口伪终端、SQLite、HTTP 与前端构建。
2. 上游对照：固定输入下对比原实现与 Rust 输出；记录原实现缺陷及有意修正。
3. OpenWrt：SDK 交叉编译、包安装、LuCI ACL、procd 生命周期。
4. 实机：ARM64/x86、USB/PCIe、实际厂商平台的拨号和短信；没有实机证据时标为未验证。
